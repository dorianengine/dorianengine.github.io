My games
These are some of the games or concepts I have worked on during my time at the University College of Albert Jacquard.
OFEU ARCADE

OFEU ARCADE is an arcade base game in which you need to save the student from a school aflame.

As training to learn the basics and more of the blueprint system of Unreal Engine, I worked alone on this project following an online course and with the help of external YouTube videos and Reddit posts, as well as the official documentation for Unreal Engine. I was able to create a game with an atypical level design and a fun concept, as well as understanding this engine better.

Be still

Be still is a survival horror game centered around platforming and avoiding the gaze of an entity while you need to wind up to stay alive!

During a 3 week workshop where the theme was survival horror, we were a group of 2 programmers, 1 tech artist, 2 game designers, 2 game artists and 1 sound designer (me).
In this period we created a short thrilling experience following three pillars: gigantism, childhood and anxiety.
This project was a favorite of the internal jury for the 3rd year bachelor in video game study at the HEAJ.

Snuff out!

Snuff out! is a LAN-based multiplayer deduction game made in Unreal Engine.

Lanterns must snuff out a hidden candle causing trouble in a cult. Made in a 2-week multiplayer workshop; I was the group’s producer.

The wrong path stories: Summit

Summit is a narrative game prototype in which the player negotiates with a country ruled by old acquaintances to form an alliance with other powers.

I designed the visuals, world, assets and dialogue, and coded the game in Twine (Harlowe), with multiple endings. Development is ongoing.

Engine failure

Engine failure is a game jam prototype on the theme “out of control”: an Overcooked × Among Us-style game where an engineer keeps trains running as long as possible.

I managed a Miro board and Discord for team communication across a 10-person team.

In Straight Line

In Straight Line is a third-person 3D narrative puzzle game about a veteran who discovers a forest’s secret while trekking.

Created in a second-year platformer assignment with restricted controls, where I designed the onboarding and the rope mechanic, and made a pitch deck.

Ofeu

Ofeu is a puzzle game concept, also called “Aflame” in English, in which a teacher uses a multitask fire extinguisher to save the school from an unintelligent AI.

Created on Pico-8 from a classroom prefab, and later expanded with key features and puzzles.
